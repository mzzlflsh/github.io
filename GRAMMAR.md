# Как устроен учебник Eesti2000

Все правила раздела «Учебник» хранятся в одном файле **`grammar.csv`**:
- на GitHub Pages — в корне репозитория, рядом с `index.html` и `dictionary.csv`;
- в исходниках — в `public/grammar.csv`.

**Пересобирать приложение не нужно.** Замените `grammar.csv` на сайте — при следующем открытии «Учебника» приложение скачает новую версию. Последняя удачная копия хранится на телефоне, поэтому учебник работает и без интернета. Если в новом файле нет ни одного правила (например, загрузили не тот файл), приложение оставит старую копию.

Учебник никак не связан с прогрессом: правила можно менять, переставлять и удалять сколько угодно.

**Ссылки с карточек.** В словаре есть колонка `grammar` — в ней `id` правила отсюда. Тогда на обороте карточки появляется «Читайте в учебнике: <название правила>» (подробнее — в DICTIONARY.md). Поэтому `id` правил лучше не менять: если всё же поменяли, поправьте его и в `dictionary.csv`. Проверка: `npm run check:dictionary`.

## Формат файла

CSV в кодировке UTF-8, разделитель — **точка с запятой** `;`. Первая строка — заголовок:

```
level;section;rule;block;content;translation;id
```

**Одна строка — один блок правила.** Строки с одинаковыми `level` и `rule` собираются в одну раскрывающуюся панель. Блоки идут в том порядке, в каком стоят в файле; правила и разделы — в порядке первого появления.

| Колонка | Обязательно | Что писать |
|---|---|---|
| `level` | да | `A1`, `A2`, `B1` или `B2` — вкладка сверху |
| `section` | желательно | Раздел внутри уровня: «Местоимения», «Глаголы», «Падежи»… Без раздела правило попадёт в «Разное» |
| `rule` | да | Название правила — заголовок панели. Одинаковое во всех строках правила |
| `block` | да | Тип блока, см. ниже |
| `content` | да | Текст блока |
| `translation` | только у `example` | Перевод примера |
| `id` | нет | Постоянный идентификатор правила (`a1-pronouns`). Достаточно указать в первой строке правила. На него ссылается словарь (колонка `grammar`) |

### Типы блоков

| `block` | Как выглядит | `content` |
|---|---|---|
| `summary` | Краткое описание под названием (видно в свёрнутой панели) | Одна-две строки |
| `text` | Абзац | Обычный текст |
| `heading` | Подзаголовок внутри правила | Короткая фраза |
| `tip` | «Подсказка»: синяя рамка с лампочкой | Совет, полезное наблюдение |
| `note` | «Запомните»: жёлтая рамка со значком «i» | Исключение или то, что надо выучить целиком |
| `warn` | «Частая ошибка»: красная рамка с треугольником | Типичная ошибка и правильный вариант: `«Ma ei tean». Правильно: **Ma ei tea**.` |
| `head` | Заголовок таблицы | Ячейки через `\|`: `Лицо \| Кто? \| Кого?` |
| `row` | Строка таблицы | Ячейки через `\|`: `я \| mina, ma \| mind` |
| `example` | Пример: эстонский текст и перевод серым | `content` — по-эстонски, `translation` — по-русски |

- Таблица начинается со строки `head` и продолжается строками `row` до следующего блока другого типа. Таблица без заголовка — просто строки `row` подряд. Число ячеек в строках должно совпадать с заголовком.
- Первая ячейка заголовка может быть пустой: ` | Есть | Нет`.
- **Выделение:** окончания и важные части берите в двойные звёздочки — `linna**s**`. В приложении они будут жирными и синими. Работает в любом блоке и в ячейках таблиц.
- В одном `example` можно дать два варианта через ` • `: `Minu nimi on Anna. • Mu nimi on Anna.`
- Внутри текста лучше не использовать `;`. Если нужно — возьмите поле в двойные кавычки. Сами кавычки в тексте пишите «ёлочками».

### Пример правила

```
level;section;rule;block;content;translation;id
A1;Падежи;С кем? Без чего? -ga, -ta;summary;sõbraga — с другом, ilma suhkruta — без сахара.;;a1-comitative
A1;Падежи;С кем? Без чего? -ga, -ta;text;**-ga** = «с кем, с чем». **-ta** = «без», часто вместе со словом **ilma**.;;
A1;Падежи;С кем? Без чего? -ga, -ta;head;Слово | С | Без;;
A1;Падежи;С кем? Без чего? -ga, -ta;row;sõber — друг | sõbra**ga** | sõbra**ta**;;
A1;Падежи;С кем? Без чего? -ga, -ta;row;piim — молоко | piima**ga** | ilma piima**ta**;;
A1;Падежи;С кем? Без чего? -ga, -ta;example;Ma räägin sõbraga.;Я разговариваю с другом.;
A1;Падежи;С кем? Без чего? -ga, -ta;tip;Транспорт тоже с -ga: bussiga — на автобусе.;;
```

## Как добавить правило или раздел

1. Откройте `grammar.csv` в текстовом редакторе (не в Excel — он может сменить кодировку и разделитель).
2. Допишите строки нового правила в нужное место. Новый раздел появится сам, как только встретится новое значение в `section`. Новый уровень — то же самое: просто напишите `B1` или `B2` в колонке `level`.
3. Проверьте файл: `npm run check:grammar` в исходниках (покажет ошибки, предупреждения и список правил).
4. Загрузите `grammar.csv` на сайт так же, как словарь: GitHub → **Add file → Upload files** → перетащить файл → **Commit changes**.

Проверка ловит: неизвестный уровень или тип блока, пустые поля, пример без перевода, кириллицу в эстонском примере, строку таблицы с другим числом ячеек, повторяющиеся `id`.

## Что сейчас в учебнике

**A1 — 26 правил:**
- Основы: как устроен эстонский; буквы и произношение.
- Местоимения: личные местоимения и их формы; «у меня есть» — mul on.
- Вопросы: вопросительные слова; вопрос «да или нет» с kas.
- Глаголы: olema; настоящее время; отрицание ei; два инфинитива -ma и -da; прошедшее время; повелительное наклонение.
- Существительные: три основные формы; множественное число -d; прилагательные (suur maja — suured majad); после чисел и слов количества; дополнение «кого? что?».
- Падежи: обзор всех 14 падежей; где? куда? откуда? (-s/-sse/-st, -l/-le/-lt); здесь, сюда, отсюда (siin, siia, siit); послелоги места (peal, all, ees, taga, kõrval, juures); кому? у кого? от кого?; с кем? без чего? (-ga, -ta).
- Числа и время: числа; который час; дни, месяцы и части суток.

**A2 — 29 правил:**
- Множественное число: форма «чьих?» (-de / -te); падежи мн. числа (majades, sõpradega); «кого? что?» во мн. числе.
- Прилагательные и наречия: сравнение (suurem, kõige suurem); наречия (kiiresti, hästi, paremini).
- Падежи и послелоги: -ks и -na; до чего? -ni; послелоги kohta, jaoks, ajal, eest; глаголы и их падежи; целиком или частично (raamatut или raamatu).
- Местоимения: end, endale, ise; keegi, miski, kunagi; который — kes, mis, kus.
- Глаголы, времена: прошедшее время частых глаголов; перфект (olen käinud) и когда его выбирать; давнопрошедшее (olin käinud).
- Глаголы, наклонения и формы: условное наклонение; безличная форма; формы -ma, -mas, -mast, -mata; ещё о форме -da; составные глаголы; давай(те) — lähme, ärme; можно, нужно, должен.
- Числа и время: числа в падежах; даты и годы; когда? как долго? как часто?
- Предложение: союзы et, sest, kui, kuigi, kas; порядок слов.
- Словообразование: суффиксы -ja, -mine, -la, -lane, -ne, -lik, -tu.

**B1 — 1 правило:**
- Глаголы: форма на -des — «делая» (vaadates, minnes).

В уроках есть три вида подсказок: «Подсказка», «Запомните» и «Частая ошибка» (типичные ошибки русскоязычных).

Правила составлены по учебнику «E nagu Eesti» и материалам курсов Тартуского университета (keeleweb). Формы и примеры сверены с открытыми справочниками (Sõnaveeb, Wikipedia, Omniglot).

## Запрос для ИИ, чтобы добавить правило

```
Ты пишешь учебник грамматики эстонского языка для русскоязычных новичков.
Напиши правило уровня B1 «Причастия: tegev, tehtud» для раздела «Глаголы».

Формат — строки CSV с разделителем «;», 7 колонок:
level;section;rule;block;content;translation;id
- block: summary (1 строка), text, heading, tip (совет), note (запомните, исключение), warn (частая ошибка), head/row (таблица, ячейки через « | »), example.
- example: content — по-эстонски, translation — перевод на русский.
- Окончания выделяй **так**. Кавычки — только «ёлочки». Без «;» внутри текста.
- id — только в первой строке правила, латиницей: b1-participles.
- Объясняй просто, короткими фразами, 2–3 таблицы максимум, 4–6 примеров.
- Проверь каждую форму и каждый пример: только правильный современный эстонский.
- Без пояснений до и после — только строки CSV, без строки заголовка.
```

Полученные строки добавьте в конец `grammar.csv`, проверьте `npm run check:grammar` и загрузите файл на сайт.
