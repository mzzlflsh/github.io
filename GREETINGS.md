# Как устроены приветствия Meelde

На главном экране вместо постоянного «Tere!» — эстонская фраза с эмодзи: утром — утренняя, вечером — вечерняя, в пятницу — «Хороших выходных!», 24 февраля — поздравление с Днём независимости, а иногда просто случайная. Фраза подчёркнута пунктиром: нажатие открывает подсказку с переводом, пояснением, примерами и вариантом ответа.

Все фразы хранятся в одном файле **`greetings.csv`**:
- на GitHub Pages — в корне репозитория, рядом с `index.html`, `dictionary.csv` и `grammar.csv`;
- в исходниках — в `public/greetings.csv`.

**Пересобирать приложение не нужно.** Замените `greetings.csv` на сайте — приложение скачает новую версию при ближайшей проверке обновлений: само раз в 7 дней (и сразу после новой версии приложения) или по кнопке «Настройки → Проверить обновления». Копия хранится на телефоне, поэтому без интернета всё работает. Если файла нет или он сломан, показывается запасное «Tere! 👋».

Приветствия никак не связаны с прогрессом: фразы можно менять, добавлять и удалять сколько угодно.

## Формат файла

CSV в кодировке UTF-8, разделитель — **точка с запятой** `;`. Первая строка — заголовок:

```
id;estonian;emoji;russian;usage;examples;reply;hours;days;dates;weight
```

**Одна строка — одна фраза.**

| Колонка | Обязательно | Что писать |
|---|---|---|
| `id` | нет | Короткий постоянный идентификатор (`tere-hommikust`). Если пусто — берётся из фразы |
| `estonian` | да | Фраза по-эстонски, как её покажут на главном экране: `Tere hommikust!` |
| `emoji` | желательно | Один эмодзи после фразы: `🌅` |
| `russian` | да | Перевод: `Доброе утро!` |
| `usage` | желательно | «Когда говорят» — одно-два предложения: кому, в какой ситуации, официально или нет |
| `examples` | желательно | Примеры: `фраза — перевод`, несколько — через ` • ` |
| `reply` | желательно | «Как ответить» — в том же виде, что и примеры |
| `hours` | нет | Часы, когда фразу можно показывать (см. ниже). Пусто — в любое время |
| `days` | нет | Дни недели. Пусто — в любой день |
| `dates` | нет | Даты. Пусто — в любую дату |
| `weight` | нет | Вес — насколько часто выпадает фраза. Пусто — 1 |

Между фразой и переводом в `examples` и `reply` — **тире с пробелами** ` — `:

```
Tere, Mari! — Привет, Мари! • Tere! Kuidas läheb? — Здравствуйте! Как дела?
```

Если в тексте нужна точка с запятой, возьмите всё поле в двойные кавычки.

## Когда показывается фраза

| Колонка | Как писать | Пример |
|---|---|---|
| `hours` | `с-до` по местному времени телефона, «до» не включается. Через запятую — несколько промежутков. Можно через полночь | `5-11` — с 5:00 до 10:59; `18-24` — с 18:00 до полуночи; `22-5` — с 22:00 до 4:59; `12-14,18-20` — обед и ужин |
| `days` | 1 — понедельник … 7 — воскресенье, включительно | `1` — понедельник; `1-5` — будни; `5-6` — пятница и суббота |
| `dates` | `ММ-ДД` или `ММ-ДД..ММ-ДД`, включительно. Можно через Новый год | `02-24`; `12-20..12-26`; `12-31..01-05`; `03-01..05-31` — вся весна |

Если заполнено несколько колонок, должны совпасть **все**: `Jõudu tööle!` с `hours = 8-18` и `days = 1-5` показывается только в будни днём.

## Как выбирается фраза

1. Приложение берёт все фразы, которые подходят к текущему моменту (часы, день недели, дата).
2. Выбирает одну случайно с учётом веса: фраза с весом 3 выпадает втрое чаще фразы с весом 1.
3. Выбранная фраза держится, пока подходящие фразы те же: при переходах между вкладками приветствие не меняется, а утром само сменится на утреннее.

Веса сейчас:

| Что | Вес | Примеры |
|---|---|---|
| «Просто» приветствия — в любое время | 1 (`Tere!` — 3) | `Tervist!`, `Tšau!`, `Kuidas läheb?`, `Kõike head!` |
| По времени суток | 2–3 | `Tere hommikust!`, `Tere õhtust!`, `Head isu!` |
| По дню недели | 4 | `Head nädala algust!`, `Head nädalavahetust!` |
| По сезону | 2 | `Ilusat kevadet!`, `Ilusat sügist!` |
| Праздники | 50 | `Häid jõule!`, `Head vabariigi aastapäeva!` |

В обычный день «просто» фразы и фразы «по времени» выпадают примерно поровну. В праздник его поздравление появляется в большинстве случаев, но не всегда.

## Как проверить файл

```bash
npm run check:greetings
```

Покажет список фраз с условиями, ошибки (такие строки не попадут в приложение) и предупреждения: нет эмодзи, нет примеров, нет перевода у примера. Заодно проверит, что в любой час любого дня года есть хотя бы одна фраза.

## Как заменить файл на GitHub

1. Откройте репозиторий → файл `greetings.csv` → значок карандаша (или **Add file → Upload files** и загрузите новый файл поверх старого).
2. **Commit changes**.
3. Через 1–2 минуты на сайте будет новая версия. Приложение подхватит её при ближайшей проверке обновлений (или нажмите «Настройки → Проверить обновления» — новые фразы появятся со следующего запуска).

## Запрос для ИИ, чтобы пополнить приветствия

```
Добавь в greetings.csv приложения Meelde ещё N эстонских приветствий или пожеланий
(тема: …). Формат — CSV с разделителем «;», колонки:
id;estonian;emoji;russian;usage;examples;reply;hours;days;dates;weight

Правила:
- только живые, употребительные фразы с правильной эстонской орфографией (õ, ä, ö, ü, š);
  если не уверен, что эстонцы так говорят, — не добавляй;
- usage — по-русски, 1–2 предложения: кому и когда говорят, официально или нет;
- examples — 1–2 коротких примера «фраза — перевод» через « • »;
- reply — как обычно отвечают, в том же виде;
- hours «с-до» (до не включается), days 1–7 (пн–вс), dates ММ-ДД или ММ-ДД..ММ-ДД;
- weight: обычные фразы 1, по времени суток 3, по дню недели 4, по сезону 2, праздники 50;
- внутри полей не используй «;».
Выведи только новые строки без заголовка.
```

## Похвалы дня — praise.csv

Когда выполнена «Цель на день», приложение поздравляет эстонской **похвалой дня**: плашка с конфетти, а потом фраза остаётся на главном экране — на неё можно нажать, чтобы увидеть перевод, примеры и как ответить. Фразы лежат в отдельном файле **`praise.csv`**, формат — точно как у `greetings.csv` (те же 11 колонок).

Отличия от приветствий:

- колонки `hours`, `days`, `dates` оставляйте **пустыми** — похвала дня одна на весь день;
- фраза выбирается **по дате**: весь день одна и та же (на плашке, на главном экране и в окне с переводом), на следующий день — другая;
- `weight`: самые частые похвалы (`Tubli!`, `Väga tubli!`, `Hästi tehtud!`, `Hea töö!`, `Said hakkama!`) — 3, обычные — 2, разговорные (`Vägev!`, `Äge!`, `Lahe!`…) — 1;
- если файла нет или он не скачался — показывается запасное «Tubli! ⭐ — Молодец!».

Проверка: `npm run check:praise` (ошибки, предупреждения, список фраз с весами). Заменить на GitHub — так же, как `greetings.csv`; приложение подхватит новый файл при ближайшей проверке обновлений.

Запрос для ИИ:

```
Добавь в praise.csv приложения Meelde ещё N эстонских похвал (за выполненную дневную цель).
Формат — как у greetings.csv, разделитель «;», колонки:
id;estonian;emoji;russian;usage;examples;reply;hours;days;dates;weight
Правила: только живые, употребительные похвалы с правильной орфографией (проверяй на sonaveeb.ee);
usage — по-русски, 1–2 предложения (разговорное или нейтральное); examples — 2 примера «фраза — перевод»
через « • »; reply — как ответить (можно пусто); hours, days, dates — пустые; weight 1–3;
внутри полей не используй «;». Выведи только новые строки без заголовка.
```
