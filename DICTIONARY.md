# Как вносить слова в словарь Meelde

Все слова, словосочетания и предложения хранятся в файле **`dictionary.csv`** (переводы на русский), а для тех, кто учит эстонский на английском, — в **`dictionary_en.csv`** (см. «Английский словарь» ниже):
- на GitHub Pages — в корне репозитория, рядом с `index.html`;
- в исходниках — в `public/dictionary.csv` и `public/dictionary_en.csv`.

В приложении слова не редактируются: там темы только включаются, выключаются и просматриваются.

**Пересобирать приложение не нужно.** Замените `dictionary.csv` на сайте. При ближайшей проверке обновлений (приложение проверяет их само раз в 7 дней и сразу после новой версии приложения) или по кнопке «Настройки → Проверить обновления» приложение скачает файл и сверит с ним базу:
- новые слова добавятся;
- у изменённых слов обновятся переводы, примеры, тема и уровень, а прогресс сохранится;
- слова, удалённые из файла, скроются. Их прогресс не пропадёт: если слово вернётся в файл, прогресс восстановится.

**Файл с ошибками не применяется (с версии 1.8).** Если хотя бы одна строка файла с ошибкой (неизвестный уровень, пустой перевод, лишняя «;» и т. п.), приложение не трогает уже загруженный словарь: у пользователей всё остаётся как было, кнопка «Обновить словарь» сообщит, что в новой версии есть ошибки. Исправьте файл — при следующем запуске он применится. Поэтому **перед загрузкой проверяйте файл** командой `npm run check:dictionary` (см. «Как проверить файл»). Исключение — самый первый запуск приложения: тогда берутся правильные строки, чтобы приложение не было пустым.

## Формат файла

CSV в кодировке UTF-8, разделитель — **точка с запятой** `;`. Первая строка — заголовок, её не меняйте:

```
level;type;topic;estonian;russian;english;example;notes;id;grammar
A1;word;Еда и напитки;leib;хлеб (чёрный);(rye) bread;;Белый хлеб — sai;;
A1;word;Действия;minema;идти, уходить;to go;;ma lähen — я иду;;a1-infinitives
A1;word;Страны;Eesti;Эстония;Estonia;Ma elan Eestis. — Я живу в Эстонии.;Имя собственное;;
A2;phrase;Повседневные дела;tööle minema;идти на работу;to go to work;;;;a1-where
A1;sentence;Язык;Ma ei saa aru.;Я не понимаю.;I don't understand.;;;;a2-particle-verbs
```

| Колонка | Обязательно | Что писать |
|---|---|---|
| `level` | да | `A1` — базовые, `A2` — простые, `B1` — средние, `B2` — сложные |
| `type` | нет | `word` — слово (по умолчанию), `phrase` — словосочетание, `sentence` — предложение |
| `topic` | да | Название темы по-русски. Новое название сразу создаёт новую тему |
| `estonian` | да | Эстонское слово, словосочетание или предложение |
| `russian` | нужен хотя бы один перевод | Русский перевод. Синонимы — через запятую: `сразу, сейчас же` |
| `english` | | Английский перевод. Глаголы — с `to`: `to go` |
| `example` | нет | Пример: `Täna sajab vihma. — Сегодня идёт дождь.` Несколько примеров — через ` • ` (см. ниже) |
| `notes` | нет | Подсказка: формы слова, множественное число, форма «я …», «Имя собственное» |
| `id` | только для омонимов | См. «Одинаковые слова» |
| `grammar` | нет | Ссылка на правило учебника — `id` правила из `grammar.csv`, например `a1-present`. На обороте карточки появится «Читайте в учебнике: …» (см. ниже) |

- В каждой строке 9 точек с запятой (10 колонок), даже если колонки в конце пустые. Строки без последней колонки `grammar` (8 точек с запятой) тоже читаются.
- **Внутри текста не используйте `;`.** Если без неё никак, возьмите поле в двойные кавычки: `"один; два"`.
- Порядок строк неважен. Порядок тем в приложении — порядок их первого появления в файле.

### Несколько примеров

Если у слова несколько значений или его удобнее показать в разных ситуациях, впишите несколько примеров в одну колонку `example` через знак ` • ` (пробел, точка-маркер, пробел):

```
A1;word;Вопросительные слова;kus;где;where;Kus sa elad? — Где ты живёшь? • Kus on tualett? — Где туалет?;Ответ обычно с -s или -l: koolis, tööl;
```

В карточке и в словаре каждый пример показывается отдельной строкой. Хватит двух-трёх примеров: оборот карточки должен помещаться на экран.

### Пример на лицевой стороне

**Первый** пример виден ещё и на лицевой стороне, под самим словом (настройка «Пример на карточке», по умолчанию включена). При эстонской лицевой стороне показывается часть до « — », при русской — часть после. Поэтому:
- ставьте первым самый простой и короткий пример;
- между фразой и переводом — обязательно тире с пробелами ` — `;
- в эстонской части не пишите русских слов (кроме случаев вроде «Kuidas öelda eesti keeles «спасибо»?»): иначе лицевая сторона подскажет ответ.

Пример и перевод разделяются по **первому** « — », поэтому тире внутри русского перевода допустимо (`Kolm pluss neli on seitse. — Три плюс четыре — семь.`), а внутри эстонской части — нет.

Если пример совпадает с самой карточкой (у «tubli» пример «Tubli!»), на лицевой стороне его не будет.

Правила грамматики (склонения, окончания, таблицы) лежат не здесь, а в отдельном файле `grammar.csv` — см. `GRAMMAR.md`.

## Разделы и темы

Раздел — это тип и уровень вместе: «Базовые слова» (word + A1), «Простые словосочетания» (phrase + A2) и т. д. Тема живёт внутри раздела: «Еда и напитки» в A1 и в A2 — две разные темы, их можно включать по отдельности.

- Новые темы **слов A1** включаются в обучение сразу; фразы и предложения A1 и все темы A2–B2 — выключены, пользователь включает их сам в «Словаре». (До версии 1.8 сразу включались все темы A1; у уже установленного приложения включённость тем не меняется.)
- Цвет темы подбирается по названию автоматически.

## Английский словарь — dictionary_en.csv

С версии 1.8.9 эстонский можно учить на русском или на английском («Настройки» → «Язык обучения»). У английского — свой файл `dictionary_en.csv`. В нём **те же слова в том же порядке**, что и в `dictionary.csv`, только переводы, примеры, заметки и названия тем — по-английски. Прогресс, история и включённые темы при смене языка не меняются: слова и темы в обоих файлах узнаются по одним и тем же id.

```
level;type;topic;topic_id;estonian;english;example;notes;id;grammar
A1;word;Food and drink;Еда и напитки;leib;bread;Ma ostan leiba. — I'm buying bread.;;;
A2;word;Health;Здоровье;arst;doctor;Ma lähen arsti juurde.;;;
```

Отличия от русского файла:
- колонки `russian` нет, перевод — в `english`;
- **`topic`** — английское название темы (его видит пользователь), **`topic_id`** — русское название той же темы из `dictionary.csv`. По `topic_id` приложение понимает, что «Food and drink» — это та же тема, что «Еда и напитки»: её включённость и цвет сохраняются. Если `topic_id` пустой, тема узнаётся по `topic`, как в русском файле;
- `example`: `Эстонская фраза. — English translation.`; можно и только эстонскую фразу, без перевода — она покажется под словом на эстонской стороне и на обороте;
- заметка «Proper noun» (или «Contains a proper noun») — для слов с заглавной буквы, как «Имя собственное» в русском файле;
- `estonian`, `level`, `type`, `id` и `grammar` — **точно такие же, как в `dictionary.csv`**. Если поменять эстонское слово, уровень или тему только в одном файле, при смене языка прогресс или включённость тем не совпадут. Добавляете слово — добавляйте его в оба файла.

Сейчас в английском словаре: у слов A1 (812) — английские примеры с переводом и заметки; у остальных карточек — английский перевод и эстонский пример без перевода, заметок пока нет. `npm run check:dictionary` показывает, сколько ещё осталось перевести.

## Как заменить файл на GitHub

Сайт приложения живёт в репозитории `mzzlflsh/github.io`, файл словаря лежит в его корне рядом с `index.html`.

**С компьютера (проще всего):**
1. Откройте https://github.com/mzzlflsh/github.io и войдите в аккаунт.
2. Нажмите **Add file → Upload files**.
3. Перетащите новый `dictionary.csv` в окно. Имя должно быть ровно `dictionary.csv`, маленькими буквами. Файл с таким же именем GitHub заменит сам.
4. Внизу нажмите **Commit changes**.
5. Подождите 1–3 минуты: GitHub пересоберёт сайт (вкладка **Actions**, зелёная галочка у «pages build and deployment»).
6. Проверьте файл в браузере: https://mzzlflsh.github.io/github.io/dictionary.csv — должен открыться новый текст.

**Другой способ:** откройте `dictionary.csv` в репозитории → значок карандаша → вставьте весь текст нового файла вместо старого → **Commit changes**. Подходит для мелких правок.

**Перед загрузкой:** проверьте файл на компьютере — `npm run check:dictionary`, ошибок быть не должно (файл с ошибками приложение не применит).

**В приложении на айфоне:** «Настройки → Проверить обновления». Прогресс по словам сохранится, новые темы слов A1 включатся сами, остальные включаются в «Словаре».

**Если словарь не обновился:**
- GitHub отдаёт файлы через кэш до 10 минут — подождите и нажмите «Проверить обновления» ещё раз;
- проверьте, что файл лежит в корне, а не в папке, и называется именно `dictionary.csv`;
- не открывайте и не сохраняйте файл в Excel: он может сменить кодировку и разделитель. Если нужно посмотреть таблицу, откройте копию.

## Как выбирать слова и формы

Главное правило: **чем употребительнее, тем лучше**. На A1 и A2 берите базовую словарную форму. Падежную форму или множественное число — только если именно так слово говорят чаще.

- **Существительные** — именительный падеж единственного числа: `raamat`, `maja`. Множественное число — для слов, которые так и употребляются: `püksid`, `prillid`. В заметке: `Мн. ч.` или `Мн. ч. от juus`.
- **Глаголы** — форма на **-ma**: `minema`, `tegema`. Для A1 в заметке полезна форма «я»: `ma lähen — я иду`.
- **Прилагательные** — именительный падеж: `suur`, `ilus`.
- **Составные слова** — в заметке состав: `Состоит из: kiire (быстрый) + abi (помощь)`. Если слово образовано от выражения, так и пишите: `От ette panema — предлагать: ette (вперёд) + panema (класть)`.
- **Застывшие падежные формы** можно давать как есть: `kodus` (дома), `vasakule` (налево). В заметке: `Форма от kodu`.
- **Имена собственные** (страны, города) — с заглавной буквы, в заметке `Имя собственное`.
- **Словосочетания** (`phrase`) — со строчной буквы, без точки: `head isu`.
- **Предложения** (`sentence`) — с заглавной буквы и со знаком препинания в конце: `Kuidas läheb?`.

## Ссылка на учебник (колонка grammar)

Если в колонке `grammar` указан `id` правила из `grammar.csv`, на обороте карточки под примерами появляется кнопка «Читайте в учебнике: <название правила>». Нажатие открывает «Учебник» сразу на этом правиле; вернуться к карточке — кнопкой «К карточке» или вкладкой «Учить», сессия при этом не прерывается.

- Одна строка — одно правило. Выбирайте то, что объясняет главное в карточке: `Ma tahaksin süüa.` → `a2-conditional`, `Mul on kaks last.` → `a1-numbers-partitive`, `Ma tahan magada.` → `a1-infinitives`.
- Список `id` — в `grammar.csv` (колонка `id`) и в GRAMMAR.md. Если такого правила в учебнике нет, ссылка просто не появится; `npm run check:dictionary` покажет такие строки.
- Ссылки не влияют на прогресс: их можно добавлять, менять и удалять когда угодно.

**Когда ставить ссылку.** Только если правило объясняет нетривиальную форму или конструкцию, которую ученик перенесёт на другие слова. По полезности:
1. падежные формы и управление глаголов (`Millega sa tegeled?` → `a2-government`);
2. согласование и множественное число (`sinised püksid` → `a1-adjectives`, `kilo kartuleid`);
3. формы глаголов, времена, наклонения;
4. модальные и другие разговорные конструкции;
5. словообразование — только на показательных примерах (`õpetaja`, `ujumine`, `söökla`).

Без ссылки обходятся названия предметов, простые прилагательные и числа до 10, обычные глаголы в форме -ma (ссылка есть только у minema, tulema, tahtma, pidama, võima, saama, oskama, hakkama, õppima, armastama, meeldima), приветствия, пословицы и идиомы. Карточкам B1–B2 не нужны ссылки на базовые правила A1. Не ставьте ссылку по одному совпадению слова или окончания: `peal` в идиоме — не «где именно?», а `ei` в пословице — не пример отрицания.

**Уровень B1.** На B1 ссылки ставятся чаще: почти у каждой конструкции из учебника B1 (управление, составные глаголы, -ks, причастия, связки, вежливые фразы, письма). Записи B1 могут ссылаться и на правила A2, если главное объяснено там (`arstiks õppima` → `a2-translative-essive`). Ссылки у записей B1 подобраны вручную.

Сейчас ссылки есть примерно у 1430 записей.

## Одинаковые слова (омонимы)

Прогресс привязан к эстонскому написанию, поэтому одно и то же слово нельзя добавить дважды. Если у слова два значения и нужны две карточки, заполните `id` хотя бы во второй строке (у первой можно оставить пустым — тогда её прогресс не сбросится):

```
A1;word;Еда и напитки;tee;чай;tea;;Также: дорога;tee (чай)
A1;word;Транспорт и дорога;tee;дорога, путь;road, way;;Также: чай;tee (дорога)
```

## Что сохраняет прогресс

| Изменение в файле | Прогресс по слову |
|---|---|
| Перевод, пример, заметка, ссылка на учебник, тема, уровень | сохраняется |
| Удаление строки | слово скрывается, прогресс хранится до возвращения слова |
| Написание эстонского слова (без `id`) | начинается заново: для приложения это новое слово |

## Как проверить файл

- **На компьютере** (в исходниках): `npm run check:dictionary` — проверяет оба файла (`dictionary.csv` и `dictionary_en.csv`), показывает строки с ошибками и предупреждения и **сверяет файлы между собой**: те же слова, уровни, типы, темы (`topic_id`) и ссылки на учебник. В самом приложении проверки нет: обычным пользователям она не нужна.
- Если файл с ошибками всё же попал на сайт, приложение его не применит (у пользователей останется прежний словарь), а в консоли браузера будет предупреждение со списком строк.

Проверка ловит:
- пропущенные поля, неизвестный уровень или тип;
- лишнюю «;» без кавычек — строка, где колонок больше, чем в заголовке;
- повторы;
- кириллицу в эстонском тексте (например, русская «о» вместо латинской);
- буквы c, q, w, x, y;
- латиницу в русском переводе;
- предложения без точки;
- «слова» с пробелом;
- заглавную букву без пометки «Имя собственное»;
- ссылку на учебник (`grammar`) в неверном формате или на правило, которого нет в `grammar.csv` (только `npm run check:dictionary`; для английского словаря — сколько ссылок ведут на правила, которых пока нет в `grammar_en.csv`: такие ссылки просто не показываются);
- расхождения русского и английского словарей.

## Запрос для ИИ, чтобы пополнить словарь

Скопируйте запрос и подставьте уровень и тему. Перед отправкой приложите текущий `dictionary.csv`, чтобы ИИ не повторял слова.

```
Ты составляешь словарь для приложения изучения эстонского языка (для русскоязычных).
Добавь 40 самых употребительных в повседневной жизни эстонских слов уровня A2
по теме «Спорт». Не повторяй слова, которые уже есть в приложенном файле dictionary.csv.

Формат — строки CSV с разделителем «;» (точка с запятой), ровно 10 колонок:
level;type;topic;estonian;russian;english;example;notes;id;grammar

Правила:
- level: A2; type: word; topic: Спорт (дословно так).
- estonian: базовая форма. Существительные — именительный падеж ед. ч.
  (мн. ч. только если слово обычно так и употребляется, тогда в notes «Мн. ч.»).
  Глаголы — форма на -ma. Прилагательные — именительный падеж.
- russian: точный перевод, синонимы через запятую. english: перевод, глаголы с «to».
- example: короткий пример «Эстонская фраза. — Русский перевод.» только если уверен
  в его правильности, иначе пусто. Второй пример — через « • ».
- notes: пусто или краткая подсказка. Для составного слова — «Состоит из: kiire (быстрый) + abi (помощь)». id: пусто.
- grammar: пусто (ссылки на учебник лучше проставить отдельно, по списку правил из GRAMMAR.md).
- Не используй символ «;» внутри текста. Без кавычек, без пояснений до и после —
  только строки CSV, без строки заголовка.
- Проверь орфографию эстонских слов (õ, ä, ö, ü, š, ž) и правильность переводов.
```

Добавьте полученные строки в конец `dictionary.csv` и загрузите файл на сайт. Перед загрузкой проверьте: `npm run check:dictionary`. Затем в приложении: «Настройки → Проверить обновления».
