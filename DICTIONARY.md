# Как вносить слова в словарь Eesti2000

Все слова, словосочетания и предложения хранятся в одном файле **`dictionary.csv`**:
- на GitHub Pages — в корне репозитория, рядом с `index.html`;
- в исходниках — в `public/dictionary.csv`.

В приложении слова не редактируются: там темы только включаются, выключаются и просматриваются.

**Пересобирать приложение не нужно.** Замените `dictionary.csv` на сайте. При следующем запуске или по кнопке «Настройки → Обновить словарь» приложение скачает файл и сверит с ним базу:
- новые слова добавятся;
- у изменённых слов обновятся переводы, примеры, тема и уровень, а прогресс сохранится;
- слова, удалённые из файла, скроются. Их прогресс не пропадёт: если слово вернётся в файл, прогресс восстановится.

Если в файле нет ни одной правильной строки (например, загрузили не тот файл), приложение ничего не меняет.

## Формат файла

CSV в кодировке UTF-8, разделитель — **точка с запятой** `;`. Первая строка — заголовок, её не меняйте:

```
level;type;topic;estonian;russian;english;example;notes;id
A1;word;Еда и напитки;leib;хлеб (чёрный);(rye) bread;;Белый хлеб — sai;
A1;word;Действия;minema;идти, уходить;to go;;ma lähen — я иду;
A1;word;Страны;Eesti;Эстония;Estonia;Ma elan Eestis. — Я живу в Эстонии.;Имя собственное;
A2;phrase;Повседневные дела;tööle minema;идти на работу;to go to work;;;
A1;sentence;Язык;Ma ei saa aru.;Я не понимаю.;I don't understand.;;;
```

| Колонка | Обязательно | Что писать |
|---|---|---|
| `level` | да | `A1` — базовые, `A2` — простые, `B1` — средние, `B2` — сложные |
| `type` | нет | `word` — слово (по умолчанию), `phrase` — словосочетание, `sentence` — предложение |
| `topic` | да | Название темы по-русски. Новое название сразу создаёт новую тему |
| `estonian` | да | Эстонское слово, словосочетание или предложение |
| `russian` | нужен хотя бы один перевод | Русский перевод. Синонимы — через запятую: `сразу, сейчас же` |
| `english` | | Английский перевод. Глаголы — с `to`: `to go` |
| `example` | нет | Пример: `Täna sajab vihma. — Сегодня идёт дождь.` |
| `notes` | нет | Подсказка: множественное число, форма «я …», «Имя собственное» |
| `id` | только для омонимов | См. «Одинаковые слова» |

- В каждой строке ровно 8 точек с запятой, даже если колонки в конце пустые.
- **Внутри текста не используйте `;`.** Если без неё никак, возьмите поле в двойные кавычки: `"один; два"`.
- Порядок строк неважен. Порядок тем в приложении — порядок их первого появления в файле.

## Разделы и темы

Раздел — это тип и уровень вместе: «Базовые слова» (word + A1), «Простые словосочетания» (phrase + A2) и т. д. Тема живёт внутри раздела: «Еда и напитки» в A1 и в A2 — две разные темы, их можно включать по отдельности.

- Новые темы A1 включаются в обучение сразу, остальные — выключены (меняется в «Словаре» в приложении).
- Цвет темы подбирается по названию автоматически.

## Как выбирать слова и формы

Главное правило: **чем употребительнее, тем лучше**. На A1 и A2 берите базовую словарную форму. Падежную форму или множественное число — только если именно так слово говорят чаще.

- **Существительные** — именительный падеж единственного числа: `raamat`, `maja`. Множественное число — для слов, которые так и употребляются: `püksid`, `prillid`. В заметке: `Мн. ч.` или `Мн. ч. от juus`.
- **Глаголы** — форма на **-ma**: `minema`, `tegema`. Для A1 в заметке полезна форма «я»: `ma lähen — я иду`.
- **Прилагательные** — именительный падеж: `suur`, `ilus`.
- **Застывшие падежные формы** можно давать как есть: `kodus` (дома), `vasakule` (налево). В заметке: `Форма от kodu`.
- **Имена собственные** (страны, города) — с заглавной буквы, в заметке `Имя собственное`.
- **Словосочетания** (`phrase`) — со строчной буквы, без точки: `head isu`.
- **Предложения** (`sentence`) — с заглавной буквы и со знаком препинания в конце: `Kuidas läheb?`.

## Одинаковые слова (омонимы)

Прогресс привязан к эстонскому написанию, поэтому одно и то же слово нельзя добавить дважды. Если у слова два значения и нужны две карточки, заполните `id` в обеих строках:

```
A1;word;Еда и напитки;tee;чай;tea;;Также: дорога;tee (чай)
A1;word;Транспорт и дорога;tee;дорога, путь;road, way;;Также: чай;tee (дорога)
```

## Что сохраняет прогресс

| Изменение в файле | Прогресс по слову |
|---|---|
| Перевод, пример, заметка, тема, уровень | сохраняется |
| Удаление строки | слово скрывается, прогресс хранится до возвращения слова |
| Написание эстонского слова (без `id`) | начинается заново: для приложения это новое слово |

## Как проверить файл

- **В приложении:** «Настройки → Обновить словарь», затем «Проверка файла словаря». Там видны строки с ошибками (они не попали в приложение) и предупреждения.
- **На компьютере** (в исходниках): `npm run check:dictionary`.

Проверка ловит:
- пропущенные поля, неизвестный уровень или тип;
- повторы;
- кириллицу в эстонском тексте (например, русская «о» вместо латинской);
- буквы c, q, w, x, y;
- латиницу в русском переводе;
- предложения без точки;
- «слова» с пробелом;
- заглавную букву без пометки «Имя собственное».

## Запрос для ИИ, чтобы пополнить словарь

Скопируйте запрос и подставьте уровень и тему. Перед отправкой приложите текущий `dictionary.csv`, чтобы ИИ не повторял слова.

```
Ты составляешь словарь для приложения изучения эстонского языка (для русскоязычных).
Добавь 40 самых употребительных в повседневной жизни эстонских слов уровня A2
по теме «Спорт». Не повторяй слова, которые уже есть в приложенном файле dictionary.csv.

Формат — строки CSV с разделителем «;» (точка с запятой), ровно 9 колонок:
level;type;topic;estonian;russian;english;example;notes;id

Правила:
- level: A2; type: word; topic: Спорт (дословно так).
- estonian: базовая форма. Существительные — именительный падеж ед. ч.
  (мн. ч. только если слово обычно так и употребляется, тогда в notes «Мн. ч.»).
  Глаголы — форма на -ma. Прилагательные — именительный падеж.
- russian: точный перевод, синонимы через запятую. english: перевод, глаголы с «to».
- example: короткий пример «Эстонская фраза. — Русский перевод.» только если уверен
  в его правильности, иначе пусто.
- notes: пусто или краткая подсказка. id: пусто.
- Не используй символ «;» внутри текста. Без кавычек, без пояснений до и после —
  только строки CSV, без строки заголовка.
- Проверь орфографию эстонских слов (õ, ä, ö, ü, š, ž) и правильность переводов.
```

Добавьте полученные строки в конец `dictionary.csv` и загрузите файл на сайт. Затем в приложении: «Настройки → Обновить словарь» → «Проверка файла словаря».
