# Eesti2000 — версия 1.4

Карточки для изучения эстонского и справочник грамматики. Готовая сборка для GitHub Pages: всё работает без установки программ и без сборки.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `dictionary.csv` | **Словарь** — слова, фразы, предложения с примерами |
| `grammar.csv` | **Справочник** — правила грамматики с таблицами и примерами |
| `index.html` | Приложение целиком |
| `sw.js` | Работа без интернета |
| `manifest.webmanifest`, `*.png`, `favicon.svg` | Иконки и данные для установки на iPhone |
| `DICTIONARY.md` | Как заполнять словарь и запрос для ИИ |
| `GRAMMAR.md` | Как устроен справочник и как добавлять правила |
| `.nojekyll` | Отключает лишнюю обработку на GitHub (не обязателен) |

## Как опубликовать

1. Создайте на GitHub **публичный** репозиторий.
2. **Add file → Upload files** → перетащите все файлы из этого архива → **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/(root)** → **Save**.
4. Через 1–2 минуты приложение откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Как обновить

- **Словарь:** загрузите новый `dictionary.csv` поверх старого. В приложении: «Настройки → Обновить словарь». Прогресс сохранится.
- **Справочник:** загрузите новый `grammar.csv`. Приложение подхватит его при следующем открытии «Справочника».
- **Приложение:** загрузите все новые файлы поверх старых.

Прогресс, история ответов и настройки хранятся на телефоне каждого пользователя, а не на GitHub. При замене файлов они не пропадают.
