# Meelde — версия 1.8.5

Meelde — карточки для изучения эстонского и учебник грамматики (раньше приложение называлось Eesti2000). Готовая сборка для GitHub Pages: всё работает без установки программ и без сборки.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `dictionary.csv` | **Словарь** — слова, фразы, предложения с примерами и ссылками на учебник |
| `grammar.csv` | **Учебник** — правила грамматики с таблицами и примерами |
| `greetings.csv` | **Приветствия** главного экрана — фразы с эмодзи, переводом и примерами |
| `praise.csv` | **Похвалы** — эстонская фраза дня, когда выполнена «Цель на день» |
| `index.html` | Приложение целиком |
| `sw.js` | Работа без интернета |
| `manifest.webmanifest`, `*.png`, `favicon.svg` | Иконки и данные для установки на телефон |
| `DICTIONARY.md` | Как заполнять словарь и запрос для ИИ |
| `GRAMMAR.md` | Как устроен учебник и как добавлять правила |
| `GREETINGS.md` | Как устроены приветствия и похвалы, когда какая фраза показывается |
| `.nojekyll` | Отключает лишнюю обработку на GitHub (не обязателен) |

## Как опубликовать

1. Создайте на GitHub **публичный** репозиторий.
2. **Add file → Upload files** → перетащите все файлы из этого архива → **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/(root)** → **Save**.
4. Через 1–2 минуты приложение откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Как обновить

Чтобы не нагружать сайт, приложение скачивает словарь, учебник, приветствия и похвалы не при каждом открытии, а **раз в 7 дней** (и сразу после установки новой версии приложения). Проверить сразу можно в приложении: **«Настройки → Проверить обновления»**.

- **Словарь:** загрузите новый `dictionary.csv` поверх старого. Пользователи получат его при ближайшей проверке. Прогресс сохранится.
- **Учебник, приветствия, похвалы:** загрузите новый `grammar.csv`, `greetings.csv` или `praise.csv` — так же.
- **Приложение:** загрузите все новые файлы поверх старых. Новую версию браузер замечает сам при открытии приложения; вместе с ней проверяются и файлы.

Прогресс, история ответов и настройки хранятся на телефоне каждого пользователя, а не на GitHub. При замене файлов они не пропадают.

## Переезд на свой домен (например, meelde.ee)

Браузер хранит прогресс отдельно для каждого адреса сайта. На новом адресе приложение откроется «с нуля», поэтому перед переездом попросите пользователей перенести прогресс резервной копией: на старом адресе «Настройки → Сохранить резервную копию», на новом — «Настройки → Восстановить из резервной копии». На iPhone значок нового адреса нужно добавить на экран заново, а старый удалять только после переноса.
