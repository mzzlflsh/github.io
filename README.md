# Meelde — версия 1.9.0

_В коде, базе данных и именах файлов проект по-прежнему называется `eesti2000` — так прогресс пользователей сохраняется при обновлении._

Мобильное веб-приложение (PWA) для изучения эстонских слов на карточках со свайпами — на русском или на английском.
Работает без интернета, весь прогресс хранится только на устройстве (IndexedDB).

- Сессия начинается с главного экрана: выбираете размер (10, 25, 50, 100 или своё число кнопкой с карандашом) и нажимаете «Начать сессию». Незавершённую сессию можно продолжить.
- Свайп вправо или кнопка «Знаю» — слово запомнено, свайп влево или «Не знаю» — повторять чаще.
- В одной сессии слово не повторяется. Каждая сессия — случайный набор слов. «Не знаю» снижает рейтинг, и слово потом просто попадается чаще. Новые слова попадаются охотнее, чем уже знакомые («Знаю»), — так постепенно открывается весь словарь.
- На компьютере: `→` — знаю, `←` — не знаю, `пробел` — перевернуть, `Ctrl+Z` или `Backspace` — отмена.

Нижнее меню: **Учить, Учебник, Словарь, Статистика**. Настройки открываются шестерёнкой в правом верхнем углу экранов «Учить» и «Статистика».

Словарь — 5240 записей в файле **`public/dictionary.csv`**. Учебник (правила грамматики) — отдельный файл **`public/grammar.csv`**, приветствия главного экрана — **`public/greetings.csv`**, похвалы за выполненную цель на день — **`public/praise.csv`**. Для английского языка обучения — такие же файлы с `_en`: **`dictionary_en.csv`**, **`grammar_en.csv`**, **`greetings_en.csv`**, **`praise_en.csv`**. Все эти файлы загружаются с сайта, поэтому их можно заменить без пересборки. Инструкции — в **[DICTIONARY.md](DICTIONARY.md)**, **[GRAMMAR.md](GRAMMAR.md)** и **[GREETINGS.md](GREETINGS.md)** (там же — про похвалы).

### Что нового в 1.9.0 — разнообразнее карточки, спокойнее главный экран
- **Знакомые слова больше не вытесняют новые.** Раньше слово с ответом «Знаю» через несколько часов снова становилось «пора повторить» и получало бонус за просрочку — к следующему дню оно весило больше, чем ни разу не показанное слово. Поэтому одни и те же знакомые слова возвращались, а сотни слов не попадались ни разу (по реальной истории: 448 увиденных слов из 830 при 760 показах — меньше, чем дал бы простой жребий, ~498). Теперь (`src/srs/selector.ts`, `src/srs/config.ts`):
  - слово с последним ответом **«Знаю»**, которое уже можно повторить, весит 1 × вес рейтинга — без бонуса за просрочку (`KNOWN_DUE_WEIGHT`);
  - слово с последним ответом **«Не знаю»** — как раньше: от 2 до 5, чем дольше просрочено, тем больше;
  - **новое слово** — 5 (было 2,5, `NEW_WORD_WEIGHT`).
  Замер на расписании реальных сессий: повторов знакомых слов примерно втрое меньше, за то же время видно на 100+ слов больше; забытые слова возвращаются не реже, чем раньше.
- **Рейтинг не менялся:** «Знаю» +5, «Не знаю» −3, шкала 0–100, начальный 30, «изучено» от 80, интервалы повторения те же. Меняется только то, как выбирается следующая карточка, — по уже сохранённым полям. Рейтинги, история, серии, даты повторения, настройки и темы при обновлении не меняются; база (версия схемы) и формат резервной копии те же.
- **Полоска «Цель на день» не анимируется** при каждом заходе на главный экран. Раньше число ответов на мгновение было 0, и полоска «выстреливала» до настоящего значения. Теперь строка цели появляется сразу с готовым значением (пока число читается из базы — место занято, но строка невидима, экран не прыгает).
- **Настройки → «Правовая информация»** — новый последний раздел для юридических документов. Пока там строка «Документы скоро появятся здесь». Документы добавляются в `src/i18n/ru.ts` и `src/i18n/en.ts` → `settings.legalDocuments`: `{ title: 'Политика конфиденциальности', url: 'https://…' }` — строка откроет ссылку.
- **Почта для писем — `app@meelde.ee`** («Вопросы и ответы» → «Нашли ошибку или есть идея?»).
- Тесты — `tests/v190.test.ts`.

### Что нового в 1.8.9 — язык обучения: русский или английский
- **«Настройки» → «Язык обучения»** (первый раздел): **Русский | English**. На выбранном языке — переводы, примеры, заметки, названия тем, учебник, приветствия, похвалы и весь интерфейс (включая «Вопросы и ответы», ошибки и даты). Смена языка — с подтверждением; нужен интернет: приложение скачивает словарь, учебник и фразы на новом языке и перезапускается. Без интернета — понятная ошибка, ничего не меняется.
- **Прогресс при смене языка не меняется:** рейтинги, история ответов, сессии (незавершённая продолжается), включённые темы, цель и остальные настройки. В обоих словарях одни и те же слова и темы с одинаковыми id; смена — одной транзакцией (`switchDictionaryLanguage` в `src/db/repo.ts`, `src/data/languageSwitch.ts`).
- **Язык при первом запуске** определяется по языку телефона: русский → русский, любой другой → английский (`src/data/contentLanguage.ts`). У тех, кто уже пользуется приложением, язык не меняется — остаётся русский (или английский, если он был выбран вручную в старой версии; тогда словарь в базе сам досинхронизируется на английский при первом запуске с интернетом).
- **Файлы на английском** (`public/*_en.csv`): `dictionary_en.csv` — 5240 записей в том же порядке, с колонкой `topic_id` (русское название темы → тот же id темы, тот же цвет). У слов A1 — английские примеры с переводом и заметки; у остальных — английский перевод и эстонский пример (он показывается на эстонской стороне и на обороте). `grammar_en.csv` — 26 правил A1 с теми же id; на вкладках A2 и B1 — «Rules for level A2 are coming later». `greetings_en.csv` (45 фраз) и `praise_en.csv` (20 похвал) — те же фразы и условия, что у русских.
- Копии на телефоне — отдельно для каждого языка (`eesti2000.grammar.en.v1` и т. п.; у русского прежние ключи). Service worker кэширует и `*_en.csv` (сначала сеть, без интернета — последняя копия). Файлы другого языка не скачиваются, пока язык не выбран.
- **Проверки:** `npm run check:dictionary|check:grammar|check:greetings|check:praise` проверяют оба языка и сверяют файлы между собой (те же слова, уровни, темы, ссылки на учебник, id правил).
- «Вопросы и ответы»: новый вопрос «Можно ли учить эстонский на английском?», обновлены «Что такое Meelde?», «Нужен ли интернет?», «Как настроить приложение под себя?». Название в манифесте — просто «Meelde», описание — на двух языках; экран «не запустился» — на русском и английском.
- База не менялась (версия схемы та же), формат резервной копии тот же; копия, сделанная на одном языке, восстанавливается на другом (язык остаётся текущим). «Удалить все данные» сохраняет язык обучения.

### Что нового в 1.8.2 — «Цель на день»
- **Цель на день** — сколько ответов («Знаю» или «Не знаю») дать за день. По умолчанию **12**; у обновившихся тоже 12, остальные настройки и прогресс не меняются. Меняется в «Настройках» → «Цель на день» (блок сразу после «Поведения», с описанием): **Выкл | 12 | 25 | 50 | ✏️** (своё число 1–999, то же окно ввода, что у количества карточек — `NumberDialog`).
- **Главный экран:** строка «Сегодня ответов» в шапке убрана — карточка сессии поднялась. Между «Параметрами сессии» и «В обучении N карточек» — строка «Цель на день ⓘ · N из 12» с полоской. Когда цель выполнена — «Цель на день выполнена!», зелёная полоска и **похвала дня** (нажмите — откроются перевод и примеры). Если цель выключена — на этом месте «Сегодня ответов: N».
- **Поздравление** в момент выполнения цели: плашка «Цель на день выполнена!» с похвалой и **конфетти** (~2 секунды, один лёгкий canvas, ничего не блокирует; без анимаций — только плашка), **вибрация «та-да-дам»** (Android — узор, iPhone — три «тика» по нажатию), без звука. Ровно один раз за день для выбранной цели: после отмены ответа и повторного ответа не повторяется; если поднять цель — новая цель снова с поздравлением (`markGoalIfReached` в `src/db/repo.ts`, правила — `src/lib/dailyGoal.ts`).
- **Итоги сессии:** «★ Цель на день выполнена» или «До цели на день — ещё N ответов».
- **Статистика:** карточка «Цель на день» (сегодня N из 12, «Цель выполнена: X из 7 дней»), над столбцами «Последних 7 дней» — **звёздочки** (закрашена — цель выполнена), на графике — **пунктир** на уровне цели. Дни сравниваются с текущей целью.
- **Похвалы — `public/praise.csv`** (формат как у greetings.csv, 20 фраз: Tubli!, Väga tubli!, Hästi tehtud!, Said hakkama!, Jätka samas vaimus!, Vägev!, Äge! …). Фраза зависит от даты — весь день одна. Без сети — «Tubli! ⭐». Проверка: `npm run check:praise`.
- «Вопросы и ответы»: новые «Что такое «Цель на день»?» (ⓘ на главном экране ведёт сюда) и «Что значат звёздочки в статистике?»; обновлены «Сколько заниматься в день?» и «Как настроить приложение под себя?».
- База не менялась (новые поля настроек `dailyGoal`, `goalCelebrated` заполняются при чтении), резервные копии старых версий восстанавливаются с целью 12.

### Что нового в 1.8.0 — надёжность (по итогам код-ревью)
- **Испорченный dictionary.csv не применяется.** Если в файле есть строки с ошибками, приложение оставляет прежний словарь (раньше ошибочные строки «исчезали» у пользователей) и не запоминает такой файл — исправленный применится при следующем запуске. «Обновить словарь» сообщает: «в новой версии есть ошибки». Проверяйте файл перед загрузкой: `npm run check:dictionary`.
- Разбор CSV: ошибочная строка больше не блокирует следующую правильную с тем же словом; строка, где колонок больше, чем в заголовке (лишняя «;» без кавычек), — ошибка; номера строк в ошибках точные и при переносах строк внутри полей.
- **Сброс прогресса, восстановление копии и удаление данных закрывают текущую сессию** (`src/db/dataEvents.ts`): «Учить» возвращается на главный экран, старая отмена недоступна.
- **Отмена ответа защищена:** выполняется, только если ответ ещё в истории и слово с тех пор не меняли (сброс, восстановление, другая вкладка). Иначе — «Этот ответ уже нельзя отменить».
- **Резервная копия:** файл без карточек или без истории ответов отклоняется до удаления текущих данных («Резервная копия повреждена»); восстановление и «Удалить все данные» вместе со сверкой словаря — одна транзакция (при сбое всё остаётся как было); экспорт — согласованный снимок в одной транзакции.
- **Ответ записывается ровно один раз:** следующая карточка выбирается до сохранения ответа, сессия сохраняется вместе с ответом уже с новой карточкой — после перезапуска продолжается именно она.
- Учебник и приветствия снова пробуют загрузиться, если в прошлый раз не было интернета.
- Статистика: «всего ответов» и «знаю» учитывают и карточки, убранные из словаря, — как история и серии дней.
- Тексты о сохранности без обещания «надёжно»: «Данные хранятся на этом телефоне. Приложение установлено. Чтобы не потерять прогресс, иногда сохраняйте резервную копию».
- **Новым пользователям по умолчанию включены только слова A1** (812 карточек), фразы и предложения A1 включаются в «Словаре». У уже установленного приложения включённость тем не меняется.
- «Показывать ответ перед оценкой» → **«Показывать перевод перед следующей карточкой»** (поведение то же).
- Алгоритм выбора карточек не менялся (замер и предложение «забытые вперёд» — `PLAN-1.8.md`, `tests-v18/sim-selection.ts`; отложено).


## Архитектура

```
dictionary.csv (рядом с index.html) ──► скачивается при проверке обновлений (data/updateSchedule.ts, data/dictionaryLoader.ts)
                                 │ разбор и проверка (data/dictionary.ts); если файл изменился
                                 ▼
                     db/dictionarySync.ts — сверка базы с файлом, прогресс сохраняется
                                 │
React (экраны) ◄── useLiveQuery ─┤  IndexedDB (Dexie): слова, темы, ответы, сессии, настройки
                                 │
srs/ — чистая логика: планировщик повторений (ReviewScheduler), выбор карточки, сессия

grammar.csv ──► data/grammarLoader.ts ──► data/grammar.ts (разбор) ──► экран «Учебник»
                (копия в localStorage, в базу не пишется и прогресс не затрагивает)

greetings.csv ──► data/greetingsLoader.ts ──► data/greetings.ts (разбор, выбор по времени) ──► главный экран
```

- Нет сервера, регистрации и внешних запросов.
- Словарь, учебник и приветствия не встраиваются в сборку: service worker берёт их из сети (без интернета — последняя скачанная копия). В приложении темы только включаются, выключаются и просматриваются.
- Прогресс сохраняется после каждого ответа одной транзакцией. Незавершённая сессия продолжается после перезапуска (в течение 6 часов).
- Сборка — один `index.html` со встроенным JS и CSS, плюс `sw.js`, манифест и иконки. Приложение запускается на любом простом сервере, даже если тот отдаёт файлы с неверным MIME-типом. Если запуск всё же не удался, через 5 секунд появляется экран с причиной.
- Тексты интерфейса — в `src/i18n/ru.ts` и `src/i18n/en.ts` (тот же набор ключей). Язык интерфейса = язык обучения; файлы на нужном языке выбирает `src/data/contentLanguage.ts`, тексты ошибок для английского переводятся в `src/lib/errors.ts`.

## Алгоритм

**Рейтинг** (`srs/scheduler.ts`): новое слово — 30. «Знаю» — +5 (до 100), «Не знаю» — −3 (до 0). До версии 1.4 было +1 / −2; накопленный рейтинг при обновлении не меняется.
Планировщик также ставит дату следующего повторения. Интервал растёт с каждым «Знаю» подряд: 15 мин → 45 мин → 2 ч → 7 ч → 20 ч → 2,5 дня → … до 30 дней.

**Сессия** (`srs/selector.ts`, `srs/session.ts`):

1. Сессия начинается только по кнопке на главном экране. Размер — из настроек, но не больше числа доступных слов. Своё число — от 1 до 999; «∞» из версий до 1.7.5 превращается в 999.
2. В одной сессии слово показывается один раз.
3. Каждая карточка выбирается взвешенной случайной выборкой. Вес выше у слов:
   - с низким рейтингом — до ×5;
   - новых — ×2,5;
   - тех, которые пора повторить, — ×2…×5. После «Не знаю» слово сразу считается «пора повторить».

   Минимальный вес 0,02: выученные слова изредка возвращаются. Гарантированного повтора ошибок в следующей сессии нет.

**Статистика**: «изучено» — рейтинг от 80, «сложное» — рейтинг до 20 и не меньше 3 показов. В ТЗ пороги были 8 и 2 для шкалы 0–10, поэтому они пересчитаны на шкалу 0–100. Все числа — в `src/srs/config.ts`.

**Замена на SM-2 или FSRS**: новый класс с интерфейсом `ReviewScheduler`. Состояние алгоритма хранится в `word.srs`, класс возвращается из `getScheduler()`.

## Бесплатная публикация

### GitHub Pages — без сборки (рекомендуется)
1. Создайте на GitHub **публичный** репозиторий. Pages из приватного репозитория — только на платных тарифах.
2. Загрузите в корень репозитория содержимое папки `dist/` (или архива `eesti2000-v1.7-github-pages.zip`).
3. **Settings → Pages → Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/(root)** → Save.
4. Через 1–2 минуты приложение доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

Обновить словарь — заменить `dictionary.csv` в репозитории, учебник — `grammar.csv`, приветствия — `greetings.csv`, похвалы — `praise.csv` (пользователи получат их при проверке обновлений: раз в 7 дней или по кнопке «Проверить обновления»). Обновить приложение — заменить остальные файлы новыми. Прогресс хранится на устройствах пользователей и при замене файлов не пропадает.

### GitHub Pages из исходников
Загрузите исходники в репозиторий и выберите **Settings → Pages → Source: GitHub Actions**. Workflow `.github/workflows/deploy.yml` прогонит тесты, соберёт и опубликует приложение.

### Cloudflare Pages, Netlify, Vercel
Любой хостинг статических файлов: загрузите содержимое `dist/`. Из исходников: команда `npm run build`, папка `dist`.

Задел на будущее (функций пока нет):
- `settings.installId` — случайный идентификатор установки, создаётся при первом запуске;
- `meta.installId` и `meta.appVersion` в резервной копии JSON — чтобы понимать, чья копия;
- `databaseName(profile)` в `db/database.ts` — у каждого профиля может быть своя база (`eesti2000`, `eesti2000-<профиль>`). Так добавляются несколько профилей на одном устройстве без изменения остального кода;
- для синхронизации между устройствами или общей статистики понадобится сервер (например, Supabase или Firebase). Прогресс уже хранится по постоянным id слов, а резервная копия готова к переносу.

## Установка на телефон

**iPhone:** откройте адрес приложения в **Safari** → «Поделиться» → «На экран Домой» → «Добавить». У установленного приложения хранилище отдельное от вкладки Safari, прогресс переносится через резервную копию JSON.

**Android:** откройте адрес в **Chrome** → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

После первого открытия приложение работает без интернета. Инструкция с вкладками iPhone / Android есть и в самом приложении: «Установка приложения» на главном экране или в настройках.
