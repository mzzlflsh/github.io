# Eesti2000 — версия 1.1

Карточки для изучения эстонских слов. Готовая сборка для GitHub Pages: всё работает без установки программ и без сборки.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `dictionary.csv` | **Словарь.** Единственный файл, который нужно менять |
| `index.html` | Приложение целиком |
| `sw.js` | Работа без интернета |
| `manifest.webmanifest`, `*.png`, `favicon.svg` | Иконки и данные для установки на iPhone |
| `DICTIONARY.md` | Как заполнять словарь и запрос для ИИ |
| `.nojekyll` | Отключает лишнюю обработку на GitHub (не обязателен) |

## Как опубликовать

1. Создайте на GitHub **публичный** репозиторий, например `eesti2000`.
2. **Add file → Upload files** → перетащите все файлы из этого архива → **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/(root)** → **Save**.
4. Через 1–2 минуты приложение откроется по адресу `https://<ваш-логин>.github.io/eesti2000/`.

## Как обновить словарь

Откройте `dictionary.csv` на GitHub → значок карандаша (или загрузите новый файл с тем же именем) → **Commit changes**. Через 1–2 минуты откройте приложение и нажмите «Настройки → Обновить словарь». Прогресс сохранится. Формат файла и готовый запрос для ИИ — в `DICTIONARY.md` (лежит рядом).

## Как обновить само приложение

Загрузите новые файлы поверх старых. **Кроме `dictionary.csv`**, если хотите оставить свой словарь.
